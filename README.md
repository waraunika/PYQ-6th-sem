# PYQ Sorted Chapterwise
### For 6th Semester (IoE)

(minor updates are still being pushed to the repo!)

This is a collection of **Past Year Quesstions (PYQ)** of Institute of Engineering (IOE).

The subjects being worked on are based on Electronics Course's 6th Semester. The subjects are:
1. Communication English [SH 651]
2. Communication Systems [EX 656/ EX 652/ EX 702]
3. Embedded System [CT 655]
4. Object Oriented Software Engineering [CT 659]
5. Project Management [CT 658]
6. Propagation and Antenna [EX 653]

Various subjects are at various stages, with atleast one chapter of each subject being completed.
